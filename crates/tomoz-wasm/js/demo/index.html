Or drop a file on the page. A .npy array (8- or 16-bit integers, 2-D or 3-D) is compressed here first.

Header

Slice

No volume open.
Slices are decoded on demand: only the tiles of the slab on screen.

Mouse wheel, arrow keys or the slider move through slices. Drag on the image to set window and level.

Tiles

Columns are slabs of slices, rows are stripes of image rows; each tile decodes on its own. Solid: the slab on screen. Dithered: decoded and cached. Outline: never decoded.

Log

    Tomoz is open source (Apache-2.0). The decoder in this page computes exactly the same integers as the native library, so the SHA-256 check above holds on every platform.
